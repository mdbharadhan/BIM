# Nexus BIM Automation Hub 🏗️

A commercial-grade Streamlit application for managing Building Information Modeling (BIM) lifecycles, structural telemetry, and architectural analysis.

## Features
- **Executive Dashboard**: Real-time telemetry, risk alerts, and storage analytics.
- **Model Registry**: Version control and pipeline verification for `.ifc`, `.rvt`, `.dwg`, and `.pdf` files.
- **Structural Integrity**: Monitoring health indices for columns, beams, and slabs.
- **AI Co-Pilot**: Natural language queries over building records and structural risks.
